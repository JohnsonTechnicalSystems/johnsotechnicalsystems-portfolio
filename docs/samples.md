# Samples

> **Illustrative examples, not client work.** The security and compliance documents below were written for fictional businesses, and each one says so. The procedures were written for portfolio use: SOP-001 to SOP-003 document systems I built and faults I diagnosed; SOP-004 to SOP-006 are written for a generic small office. Each procedure shows its review status (Draft, Reviewed or Approved). See the [review process](about/review-process.md).

Each document states plainly what is in place, what is partial and what is planned, and lists the sources its references were checked against.
