# Samples

> **Illustrative examples, not client work.** These procedures were written for portfolio use: SOP-001 to SOP-003 document systems I built and faults I diagnosed; SOP-004 to SOP-006 are written for a generic small office. Each one shows its review status. A document marked Draft has not yet had every command and control reference checked against primary sources. See the [review process](about/review-process.md).
