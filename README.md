# johnsotechnicalsystems — Portfolio

Practical SOPs, configuration guides, and compliance documentation produced while studying for CompTIA Network+ and Security+, written to demonstrate real-world technical translation and GRC (Governance, Risk, and Compliance) consulting skills.

Every document here maps to a specific study milestone and follows a consistent template (see `/templates`). Each was drafted with a local LLM and then manually reviewed, fact-checked, and corrected before publishing — the `status` field on each doc reflects that review state honestly.

## About the review process

Documents marked `Draft` have not yet been independently verified against source material and should not be treated as authoritative. Documents marked `Reviewed` or `Published` have had every factual and compliance claim checked against primary sources (NIST SP 800-53, vendor documentation, etc.) by a human before being marked complete.
